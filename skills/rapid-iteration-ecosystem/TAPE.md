# ม้วนเทป — rapid-iteration-ecosystem

สัญญาของม้วนที่สกิลนี้อัด นั่งบน Local Code Assistant
ไม่แทน `server.py` และไม่ใช่กุญแจเข้าเครื่อง

บริษัท Token LCA · เหรียญ T-LCA · สกิล 0.1.0

## วงจรอัด

นักพัฒนาอยากได้แอปแชตหรือเว็บ ก่อนมันจะเป็นแอป
ต้องอัดมือคนทำงานเป็นไฟล์ แล้วเดินซ้ำได้โดยไม่ต้องเรียกสมองใหม่

| สเต็ป | ระบบ | ไฟล์ที่จาร | สิ่งที่ต่อ |
| --- | --- | --- | --- |
| 1 รับโจทย์จากคน | คน | — | ยังไม่มีไฟล์ |
| 2 เปิดม้วนเทป | ม้วน | `sessions/tape.json` | โจทย์ถูกจารลงม้วน |
| 3 เขียนหน้าที่คนเห็น | ฟรอนต์เอนด์ | `app/` `lca_app.py` | ห้องเว็บและหน้าต่างเดสก์ท็อป ยังไม่พูดกับโมเดล |
| 4 ต่อสายตอบทีละคำ | แบ็กเอนด์ + คอร์ | `server.py` `local_coder.py` `sysmanager/` | แชต สถานะ อุโมงค์ สตรีมทีละคำ เฝ้าสุขภาพ |
| 5 แช่แข็งสกิล | คอร์ | `SKILL.md` | รอบหน้าเดินตามม้วน ไม่เรียกสมองใหม่ |
| 6 แยกพื้นที่ | บัญชี | — | ห้องสาธารณะดูฟรี คลังส่วนตัวอยู่กับบัญชีที่ล็อกอิน |
| 7 หักเหรียญ | เหรียญ | — | 1 สเต็ปที่อัดถึง = 1 มือ T-LCA เฉพาะเก็บม้วนส่วนตัว |
| 8 แพ็กเปิดตัว | ติดตั้ง | `install/pack.json` `installer_gui.py` `install.ps1` `start-lca.bat` `Dockerfile` | วางของ เริ่มเซิร์ฟเวอร์ เปิดหน้า |

## สิ่งที่สกิลนี้ไม่ถือ

- กุญแจของ Ollama
- รหัสไททันของแอดมิน
- โทเคนเข้าเครื่องใน `Dockerfile` — คนละตัวกับเหรียญ T-LCA

ห้องสาธารณะดูได้ฟรี ไม่หักเหรียญ และไม่จำชื่อคน
เทปส่วนตัวจำโจทย์ ชื่อไฟล์ และสเต็ปที่เดินถึง เฉพาะบัญชีที่ล็อกอิน

## รูป `sessions/tape.json`

```json
{
  "skill": "rapid-iteration-ecosystem",
  "version": "0.1.0",
  "company": "Token LCA",
  "token": "T-LCA",
  "brief": "โจทย์จากคน",
  "reached": 8,
  "hands": 8,
  "steps": [{ "n": 1, "title": "รับโจทย์จากคน", "files": [], "done": true }],
  "notConnected": ["กุญแจของ Ollama", "รหัสไททันของแอดมิน", "โทเคนเข้าเครื่อง"]
}
```

`hands` เท่ากับ `reached` ห้องสาธารณะไม่หัก
สเต็ปที่ยังไม่ `done` ไม่พกชื่อไฟล์ลงม้วน
