# rapid-iteration-ecosystem

สกิลของบริษัท Token LCA ชั้นนี้นั่งบน Local Code Assistant
มันไม่แทน `server.py` และไม่ใช่กุญแจเข้าเครื่อง

## วงจรอัด

นักพัฒนาอยากได้แอปแชตหรือเว็บ ก่อนมันจะเป็นแอป
ต้องอัดมือคนทำงานเป็นไฟล์ แล้วเดินซ้ำได้โดยไม่ต้องเรียกสมองใหม่

1. รับโจทย์จากคน — ยังไม่มีไฟล์
2. เปิดม้วนเทป `sessions/tape.json`
3. เขียนหน้าที่คนเห็น — ฟรอนต์เอนด์
4. ต่อสายตอบทีละคำ — แบ็กเอนด์
5. แช่แข็งสกิลนี้ เพื่อให้รอบหน้าเดินตามรอย
6. แยกพื้นที่สาธารณะออกจากคลังส่วนตัว
7. หักเหรียญ T-LCA ตามมือที่ทำ
8. แพ็ก `install/pack.json` สำหรับเปิดตัวครั้งแรก

## ไฟล์ในรีโปที่สกิลนี้อ้างถึง

| ไฟล์ | ชั้น | หน้าที่ |
|---|---|---|
| `server.py` | แบ็กเอนด์ | เซิร์ฟเวอร์แชต สถานะ อุโมงค์ |
| `app/` | ฟรอนต์เอนด์ | ห้องที่คนเห็น |
| `local_coder.py` | คอร์ | แชตบรรทัดคำสั่ง สตรีมทีละคำ |
| `lca_app.py` | ฟรอนต์เอนด์ | หน้าต่างเดสก์ท็อป |
| `SKILL.md` | คอร์ | สกิลและบอทของ LCA |
| `sysmanager/` | แบ็กเอนด์ | เฝ้าสุขภาพและย้อนคอนฟิก |
| `installer_gui.py` `install.ps1` `start-lca.bat` | ติดตั้ง | วางของ เริ่มเซิร์ฟเวอร์ เปิดหน้า |
| `Dockerfile` | ติดตั้ง | รันตามพอร์ต โฮสต์ และโทเคนเข้าเครื่อง |

## โทเคน T-LCA

T-LCA คือเหรียญที่บริษัทออกเอง ใช้นับมือที่เอเจนต์ทำในเซสชัน
มันไม่ใช่กุญแจของ Ollama และไม่ใช่รหัสไททันของแอดมิน
ห้องสาธารณะดูได้ฟรี เทปส่วนตัวถูกจำไว้เฉพาะบัญชีที่ล็อกอิน

## ข้อมูลที่ต้องแยก

- โจทย์และชื่อไฟล์ที่เขียนในม้วน
- สเต็ปที่เดินถึง และระบบที่เชื่อมต่อ
- สิ่งที่ยังไม่ต่อ เช่น บัญชีหรือโทเคนเข้าเครื่อง
