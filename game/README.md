# เมืองคอมพิวเตอร์ (Computer City)

เกมเว็บไฟล์เดียว สอนมือใหม่ว่าคอมพิวเตอร์ทำงานยังไง ผ่านการใช้ชีวิตในเมืองที่แต่ละโซนคือชิ้นส่วนของคอมพิวเตอร์

เปิด `game/index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร (ความก้าวหน้าบันทึกใน localStorage)

| จุดในเมือง | แนวคิด | มินิเกม |
|---|---|---|
| 💡 เสาไฟ | Bit / binary | เปิดปิดหลอด 4 ดวงให้ป้ายขึ้นเลขที่ขอ |
| 🍳 ครัว | CPU, clock, core | เรียงสูตร แล้วบริหารเชฟ/นาฬิกาภายใต้งบความร้อน |
| 🗂️ โต๊ะทำงาน | RAM | จัดโต๊ะ 3 เล่มให้หยิบเร็ว แล้วลองปิดไฟ |
| 📦 คลังสินค้า | Disk, save, cache | เลือกที่วางของก่อนไฟดับ |
| 📮 ไปรษณีย์ | packet, latency, bandwidth | ส่งพัสดุที่หลุดหาย + เลือกถนนให้เหมาะกับขนาดของ |
| 🏛️ ศาลากลาง | OS, scheduler | จัดคิวงานไม่ให้ใครเดินหนี |

รูปแบบทุกด่าน: เจอปัญหา → ลองมั่ว → เห็นผล → ค่อยบอกชื่อศัพท์ + บอกว่าอุปมาหลุดตรงไหน
เลือกอาชีพตอนสร้างตัวละครเพื่อรับ "มุมมองพิเศษ" ในด่านที่ตรงกับอาชีพ
