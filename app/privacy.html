{{BUSINESS_NAME}} ("ผู้ให้บริการ") ให้ความสำคัญกับข้อมูลส่วนบุคคลของผู้ใช้บริการ LCA ตามหลักของพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) นโยบายนี้อธิบายว่าเก็บข้อมูลอะไร ใช้ทำอะไร และคุณมีสิทธิอะไรบ้าง

1. ข้อมูลที่เก็บ

  • บัญชีผู้ใช้ — ชื่อผู้ใช้ บทบาท แพ็กเกจ และรหัสผ่านที่เก็บแบบแฮช (ไม่เก็บรหัสผ่านตัวจริง)
  • อีเมลจาก Google — หากเข้าสู่ระบบด้วย Google จะเก็บอีเมลที่ Google ยืนยันแล้วเพื่อผูกกับบัญชี
  • ประวัติแชท — ข้อความที่คุณส่งและคำตอบของโมเดล เพื่อให้คุณเปิดดูย้อนหลังได้
  • API key — เก็บเฉพาะค่าแฮชของ key ไม่เก็บ key ตัวจริง (แสดงให้คุณเห็นครั้งเดียวตอนสร้าง)
  • คำสั่งซื้อ — แพ็กเกจ จำนวนเงิน ช่องทางชำระ (PromptPay หรือ Stripe) และสถานะคำสั่งซื้อ ผู้ให้บริการไม่เก็บเลขบัตรเครดิต เพราะการชำระด้วยบัตรทำบนหน้าของ Stripe
  • สถิติการใช้งาน — จำนวน token ที่ใช้ต่อเดือน เพื่อคิดโควตา

2. การประมวลผล

ข้อความแชทประมวลผลด้วยโมเดลที่รันบนเครื่องของผู้ให้บริการเองผ่าน Ollama ไม่ได้ส่งข้อความของคุณไปยังผู้ให้บริการ AI ภายนอกเพื่อสร้างคำตอบ

3. วัตถุประสงค์

ใช้ข้อมูลเพื่อให้บริการ ยืนยันตัวตน คิดโควตาและค่าบริการ ดูแลความปลอดภัยของระบบ และติดต่อเรื่องบัญชีของคุณ

4. การเปิดเผยข้อมูล

ผู้ให้บริการไม่ขายข้อมูลส่วนบุคคลของคุณ และไม่ส่งต่อให้บุคคลอื่น ยกเว้นผู้ให้บริการชำระเงิน (Stripe) เท่าที่จำเป็นต่อการชำระเงิน หรือเมื่อกฎหมายกำหนด

5. ระยะเวลาเก็บรักษา

เก็บข้อมูลบัญชีและประวัติแชทตลอดระยะเวลาที่บัญชียังใช้งานอยู่ หรือจนกว่าคุณขอลบ ข้อมูลคำสั่งซื้ออาจต้องเก็บไว้นานกว่านั้นเท่าที่กฎหมายด้านบัญชีและภาษีกำหนด

6. สิทธิของเจ้าของข้อมูล

คุณขอเข้าถึง ขอสำเนา ขอแก้ไข ขอลบ หรือคัดค้านการประมวลผลข้อมูลของคุณได้ รวมถึงถอนความยินยอมได้ทุกเมื่อ
