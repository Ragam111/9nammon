Local Code Assistant (LCA)

ผู้ช่วยเขียนโค้ด AI รันบนเครื่องคุณเอง ฟรี · ข้อมูลอยู่กับคุณ

Python stdlib ล้วน · ไม่มี dependency นอก (ยกเว้น psutil) · Windows / Linux / WSL / macOS

⭐แนะนำที่สุด: LCA-Desktop.exe — ก้อนเดียวจริง (ไม่ต้องลง Python)

ดับเบิลคลิกไฟล์เดียว → หน้าต่างแชตเปิดเลย เหมือน ChatGPT/Claude Desktop

⬇ โหลด LCA-Desktop.exe (~10 MB) หรือจาก Actions artifacts
  • ✅ ฝัง Python runtime + server มาด้วย (ผ่าน pyinstaller --onefile --add-data) → ไม่กระจายไฟล์ ไม่พึ่ง Python ภายนอก
  • ✅ ต้องมีแค่ Ollama (local mode) หรือตั้ง API key ที่ /console (cloud mode — ไม่ต้องลง Ollama)
  • ข้อมูลเก็บที่ %LOCALAPPDATA%\\LocalCodeAssistant\\data (bind 127.0.0.1 ไม่หลุดออกเครื่อง)

🔧ทางเลือก: TokenLCAlimit.exe — ตัวติดตั้ง GUI (ต้องมี Python)

ถ้ามี Python 3.10+ อยู่แล้ว + อยากติดตั้งเป็นระบบ (ใช้ CLI/server เองได้)

⬇ โหลด TokenLCAlimit.exe (~12 MB)
  • ดับเบิลคลิก → GUI → เลือกโฟลเดอร์ → ติดตั้งลง %LOCALAPPDATA%\\LocalCodeAssistant\\
  • ตรวจพื้นที่ดิสก์อัตโนมัติ (≥ 300 MB รวม TEMP) — fail-fast ถ้า Downloads/Desktop เต็ม
  • ⚠️ ต้องมี Python 3.10+ บนเครื่องปลายทาง (ตัวติดตั้งไม่ได้ฝัง Python)

1หรือติดตั้งแบบดั้งเดิม (เลือกระบบของคุณ)

Windows (PowerShell)
Linux / macOS / WSL
powershell -ExecutionPolicy Bypass -Command "iwr -useb https://raw.githubusercontent.com/Ragam111/9nammon/main/install_online.ps1 | iex"

แปะบรรทัดเดียวใน PowerShell — ดาวน์โหลด + แตกไฟล์ + ติดตั้งให้อัตโนมัติ

git clone https://github.com/Ragam111/9nammon.git && cd 9nammon && bash install.sh

หรือดาวน์โหลด zip ด้านล่างแล้วรัน bash install.sh

⬇ ดาวน์โหลด .zip ดูซอร์สบน GitHub

แบบดับเบิลคลิกล้วน (ไม่ต้องใช้เทอร์มินัล): โหลด .zip → คลิกขวา Extract → ดับเบิลคลิก install.bat → ดับเบิลคลิก start-lca.bat (เด้งเบราว์เซอร์ให้เอง)

2ดึงโมเดล (ครั้งเดียว)

ollama pull qwen2.5-coder:1.5b

ยังไม่มี Ollama? โหลดที่ ollama.com/download · ตัวติดตั้งจะแนะนำขนาดโมเดลที่เหมาะกับ RAM เครื่องคุณอัตโนมัติ

3เปิดใช้งาน

lca-web C:\path\to\project # หรือ: python server.py . --port 8420

แล้วเปิดเบราว์เซอร์ที่ http://127.0.0.1:8420 — เริ่มแชทได้เลย

มีอะไรให้ใช้

  • แชทช่วยโค้ดตอบไหลทีละคำ (สตรีม) ทั้ง CLI และหน้าเว็บ
  • ล็อกอิน + ข้อมูลส่วนตัวใช้ฟรี แต่ข้อมูลแต่ละคนแยกกัน ล็อกอินแล้วบันทึกไว้
  • พื้นที่ส่วนตัว/ทีมspaces แยก private / บริษัท ไม่ปนกัน
  • AI agent ทำงานเองรับงาน 24/7 (ต่อ n8n/automation ได้)
  • หลายเครื่องช่วยกันcluster ส่งงานไป node ที่พร้อม
  • เสียบ cloud GPU ได้สลับ backend เป็น OpenAI-compatible

ความเป็นส่วนตัว

LCA รันบนเครื่องคุณ — โค้ดและบทสนทนาไม่ออกไปไหนโดยไม่ได้ตั้งใจ. เมื่อเปิดให้คนอื่นใช้ ระบบ แยกข้อมูลตามผู้ใช้ที่ล็อกอิน (อ่าน/ลบได้เฉพาะของตัวเอง) และปฏิเสธการเปิดออกนอกเครื่อง โดยไม่มี token (ความปลอดภัยเป็นค่าเริ่มต้น).
