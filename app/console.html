เริ่มใช้งาน 3 ขั้น

1) Connections — เพิ่มสมอง เช่น OpenAI-compatible (https://host/v1 + API key) หรือ Ollama ในเครื่อง
2) Skills — ตั้ง system prompt + เลือก connection + model
3) Bots — ผูก skill แล้วเปิดใช้ → ยิง POST /api/bots/run จาก n8n ได้เลย (ต้องเปิดฟีเจอร์ Connections ที่ /dev)

เพิ่ม / แก้ Connection

สมองหนึ่งตัว = หนึ่ง connection. api_key เป็นความลับ — เก็บในเครื่อง ไม่แสดงกลับ
