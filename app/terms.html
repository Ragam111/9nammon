ข้อตกลงการใช้งาน

ข้อตกลงนี้ใช้กับบริการ LCA (Local Coding Assistant) ที่ให้บริการโดย {{BUSINESS_NAME}} การสมัครหรือใช้งานบริการถือว่าคุณยอมรับข้อตกลงนี้

1. บริการ

LCA เป็นผู้ช่วยเขียนโค้ดและแชท โดยค่าเริ่มต้นประมวลผลด้วยโมเดลภาษาที่รันบนเครื่องของผู้ให้บริการ (ผ่าน Ollama) หากผู้ให้บริการเปิดใช้และคุณเลือกโมเดล cloud (Anthropic, Google Gemini หรือบริการที่เข้ากันได้กับ OpenAI บน host อื่น) ข้อความในแชทนั้นจะถูกส่งไปยังผู้ให้บริการดังกล่าว คำตอบจากโมเดลอาจไม่ถูกต้องครบถ้วน โปรดตรวจสอบก่อนนำไปใช้งานจริง

2. บัญชีและ API key

คุณต้องดูแลรหัสผ่านและ API key ของตนเองไม่ให้ผู้อื่นใช้ หากสงสัยว่า key รั่ว ให้เพิกถอนและสร้างใหม่ได้ที่หน้า API keys

3. การใช้งานที่ไม่อนุญาต

  • ใช้บริการเพื่อกระทำผิดกฎหมาย หรือละเมิดสิทธิของผู้อื่น
  • พยายามเจาะระบบ ข้ามโควตา หรือรบกวนการให้บริการแก่ผู้ใช้อื่น
  • ส่งต่อหรือขายสิทธิ์การใช้งานโดยไม่ได้รับอนุญาต

4. แพ็กเกจ โควตา และการชำระเงิน

แพ็กเกจและจำนวน token ต่อเดือนเป็นไปตามที่แสดงในหน้า Plans ณ เวลาที่ซื้อ เงื่อนไขการยกเลิกและคืนเงินดูที่ นโยบายการยกเลิกและคืนเงิน

5. ข้อมูลส่วนบุคคล

การเก็บและใช้ข้อมูลเป็นไปตาม นโยบายความเป็นส่วนตัว

6. การระงับบริการ

ผู้ให้บริการอาจระงับบัญชีที่ฝ่าฝืนข้อตกลงนี้ และอาจหยุดให้บริการชั่วคราวเพื่อบำรุงรักษาเครื่อง

7. การเปลี่ยนแปลงข้อตกลง

หากมีการแก้ไขข้อตกลง จะแจ้งบนหน้านี้ การใช้งานต่อหลังการแก้ไขถือว่ายอมรับข้อตกลงฉบับใหม่
