Local Code Assistant v0.0.2 (Early-stage)
==========================================

ก่อนติดตั้ง อ่านตรงนี้ก่อน:

- โปรแกรมนี้เป็น AI coding assistant ที่รันผ่าน Ollama (โมเดล AI ในเครื่องคุณเอง)
  ฟรี 100% ไม่มีค่าใช้จ่าย ไม่ต้องมี internet หลัง pull โมเดลแล้ว

- ต้องติดตั้ง Python 3 และ Ollama เองแยกต่างหากก่อน (ตัวติดตั้งนี้ไม่ได้ติดตั้งให้)
  - Python: https://www.python.org/downloads/
  - Ollama: https://ollama.com/download/windows

- เวอร์ชัน 0.0.2 หมายถึง early-stage จริงๆ:
  * ฟังก์ชันหลัก (แก้ไฟล์โค้ด, todo, chat) ทดสอบแล้วบน Linux
  * ตัวติดตั้งนี้ (.exe) ยังไม่เคยถูกคอมไพล์/ทดสอบจริงบน Windows
  * โมเดล AI ขนาดเล็กที่แนะนำสำหรับเครื่อง RAM 8GB ยังมีโอกาสตอบผิดพลาด
    หรือแก้โค้ดผิดได้ ต้องตรวจทานผลลัพธ์ก่อนใช้งานจริงเสมอ

- ไม่มีการเก็บข้อมูลส่งออกไปที่ไหน ทุกอย่างรันและเก็บอยู่ในเครื่องคุณเท่านั้น
  (ยกเว้นถ้าคุณเปิดใช้ /websearch เอง ซึ่งจะส่ง query ค้นหาออกอินเทอร์เน็ต)

กดต่อไปเพื่อดำเนินการติดตั้ง
