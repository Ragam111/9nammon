# Token LCA Studio — เทปเซสชัน, โทเคนบริษัท, พื้นที่แยกข้อมูล

คู่กับคอร์สใน [`APP_WALKTHROUGH.md`](APP_WALKTHROUGH.md) ใช้ก่อนห่อแชตจะถูกห่อเป็นแอป
และก่อนข้อมูลจะถูกบันทึกถาวรต่อบัญชี

สถาปัตยกรรมยังอยู่ที่รีโปนี้ เอกสารนี้ไม่แทนตัวติดตั้ง Windows

## สิ่งที่ใช้ฟรี และสิ่งที่ต้องล็อกอิน

- แขกส่งข้อความได้ทันที คำตอบอยู่แค่ในหน้า ไม่ถูกเขียนลงเซิร์ฟเวอร์
- เทปเซสชัน ประวัติแชต และมติสภา เป็นข้อมูลของบัญชีที่ล็อกอิน
- พื้นที่ส่วนตัวกับพื้นที่บริษัทเป็นคนละถัง แชตไม่ปนกัน
- ตัวตนมาจากเซสชันฝั่งเซิร์ฟเวอร์เท่านั้น ไม่เชื่อรหัสผู้ใช้ที่เบราว์เซอร์ส่งมา

ในระบบต้นทางตัวจริงคือ `auth_backend.py` + `org_store.py` + `space_store.py`
บนเว็บคือบัญชี และพื้นที่ใน `space_store` / `history_store`

## โทเคนบริษัท Token LCA

โทเคนคือหน่วยนับการใช้สมอง ไม่ใช่รหัสผ่านร่วมทั้งบริษัท และไม่ใช่เหรียญซื้อขาย

| ของ | ความหมาย |
| --- | --- |
| โควต้าเริ่ม | 8,000 หน่วยต่อบัญชี ใช้ฟรีได้จนหมด |
| หักเมื่อ | คำตอบที่ถูกบันทึก แชตและสภา ครั้งละ 1 |
| หมด | ปฏิเสธอย่างชัดเจน ไม่เรียกสมองต่อ ข้อมูลที่บันทึกไว้ยังเป็นของบัญชีนั้น |
| ไม่ใช่รหัสร่วม | รหัสผ่านไม่แทนการแยกข้อมูล สิทธิ์ยังคือ CEO > ADMIN > USER จากเซสชัน |

ตัวนับฝั่งเซิร์ฟเวอร์คือ `usage_store.py` (ต่อคีย์ผู้ใช้) และ `conn_usage.py` (สมองภายนอก)

## ไฟล์เทปเซสชัน

แต่ละจังหวะของหนึ่งข้อความถูกเขียนเป็นหนึ่งแถว ดาวน์โหลดได้สองแบบ

- Markdown — ตาราง เวลา, ชั้น, ไฟล์, สิ่งที่เกิด
- JSON — วัตถุดิบเดียวกัน มี `steps[]` แต่ละช่องมี `at`, `layer`, `file`, `action`, `detail`

ชั้นมาตรฐานของหนึ่งข้อความในระบบต้นทาง ดู `server.py` → `auth_backend` → `space_store` → `admission` → `context_manager` → `model_backend` → `history_store` → `conn_usage`

สกิลที่บังคับให้ทุกเทิร์นที่บันทึกคือ `rapid-iteration-ecosystem` ใน [`SKILL.md`](../SKILL.md): Read → Re-check → Fix → Report

## สภา

`app/agent/personas.py` แจกมุม บริษัท / วิศวกร / ปฏิบัติการ
`app/agent/harness.py` สังเคราะห์เป็นมติเดียว
`app/agent/core.py` คือวงทำงาน
มติถูกเขียนลงเทปเช่นกัน ไม่แยกใส่ในแชตส่วนตัว

## ลำดับก่อนห่อเป็นไฟล์ติดตั้ง

1. แชตเปล่ากับโมเดล (`index.html` + `server.py` + `model_backend.py`)
2. สตรีม
3. งบเครื่อง (`resource_budget`, `admission`)
4. ล็อกอินและแยกพื้นที่
5. เทปเซสชันและโทเคน
6. สภาเอเจนต์ คอนโซล คลัสเตอร์
7. ค่อยห่อเป็น `LCA-Desktop.exe` / `TokenLCAlimit.exe`

## สตูดิโบนเว็บ

หน้าเว็บเดินเรื่องเดียวกัน ก่อนห่อจะมีไฟล์ติดตั้งบนเครื่องจริง

| หน้า | หน้าที่ |
| --- | --- |
| สตูดิโอ | แปดขั้นทีละชั้น หน้าบ้าน หลังบ้าน คอร์ พร้อมชื่อไฟล์และสิ่งที่รับส่งต่อ |
| แชท | คุยกับคนในทีม แขกไม่บันทึก ล็อกอินแล้วอัดเทปและหักโทเคน |
| ไฟล์ | เปิดชุดที่อัดไว้ ดาวน์โหลดได้ `TAPE.md` และ `TAPE.json` |
| ติดตั้ง | ลำดับจากหน้าเว็บไปหาไฟล์ `lca_app.py` และ `LCA-Desktop.exe` |
| คอนโซล | เลือกสมองในเครื่องหรือ Token LCA Cloud และดูโควต้า |

คนในทีมบนเว็บคือหน้าที่ของสามชั้น: สถาปนิก ช่างแชท ผู้ดูแลข้อมูล ช่างติดตั้ง
