# ห้องอัด Token LCA

สกิล `rapid-iteration-ecosystem` อัดมือคนทำงานกับเอเจนต์ LCA เป็นไฟล์ `sessions/tape.json`
ห้องสาธารณะดูวงจรนี้ได้ฟรี และไม่จำชื่อคนบนเซิร์ฟเวอร์
คลังส่วนตัวจำโจทย์ ชื่อไฟล์ และสเต็ปที่เดินถึง เฉพาะบัญชีที่ล็อกอิน

เหรียญ `T-LCA` นับมือที่ทำในม้วนส่วนตัว หักเฉพาะตอนเก็บม้วน
มันไม่ใช่กุญแจ Ollama ไม่ใช่รหัสไททัน และไม่ใช่โทเคนเข้าเครื่อง

ตัวอย่างห้องสาธารณะอยู่ที่ [`sessions/public-hall-tape.json`](../sessions/public-hall-tape.json)
ใบแพ็กเปิดตัวอยู่ที่ [`install/pack.json`](../install/pack.json)
