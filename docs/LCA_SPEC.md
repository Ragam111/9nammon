# LCA (Local Code Assistant) — สเปกรวมและสถานะงาน

อัปเดต: 2026-11-25 · เวอร์ชันในไฟล์ `VERSION`: 0.3.4

## เป้าหมาย
ผู้ช่วยเขียนโค้ดที่รันบนเครื่องเจ้าของ ใช้โมเดลในเครื่องผ่าน Ollama เป็นหลัก ลูกค้าใช้ผ่านเว็บใน LAN ก่อน
มือถือพักไว้ก่อน (ยังไม่อยู่ในขอบเขต)

## ส่วนประกอบ
| ส่วน | ไฟล์/คำสั่ง | สถานะ |
|---|---|---|
| เซิร์ฟเวอร์ + หน้าเว็บ | `python server.py <โฟลเดอร์> --host 127.0.0.1 --port 8420` | ใช้งานได้ |
| ไฟล์ติดตั้งก้อนเดียว | `lcalocalai.exe` (build บน GitHub Actions `build-exe.yml`) | กำลังเพิ่ม |
| แอปหน้าต่าง | `LCA-Desktop.exe`, `lca-desktop.bat` | ใช้งานได้ |
| หน้า admin | `/dev` บนเซิร์ฟเวอร์เดียวกัน (ต้องสิทธิ์ ADMIN) | ใช้งานได้ ยังไม่แยกเป็นไฟล์ HTML เดี่ยว |
| CLI | `lca.bat`, `python agents_team.py ...` | ใช้งานได้ |
| โมเดลในเครื่อง | Ollama `127.0.0.1:11434` (`qwen2.5-coder:0.5b`, `1.5b`, `qwen2.5:1.5b`) | ใช้งานได้ |

## ทีม agent (แบ่งหน้าที่)
| บทบาท | หน้าที่ | ขอบเขต |
|---|---|---|
| หัวหน้า | แบ่งงานเป็นรอบ จัดลำดับ สรุปลงไฟล์นี้ | ไม่แก้โค้ด |
| Repo | ดูแลสาขา, commit, CI | ไม่ push ไป `main` ตรง |
| Engineer | ทำเทสต์ให้ล้มก่อน แก้ให้น้อยที่สุด | แก้เฉพาะไฟล์ที่ได้รับมอบ |
| นักวิจัย/ผู้ตรวจ | พยายามทำให้ระบบพัง รันเทสต์ทั้งชุด | ไม่แก้โค้ด รายงานหลักฐาน |

กติกา loop: แก้ได้ไม่เกิน 2 รอบต่อจุด, ไม่เกิน 3 รอบต่อคำสั่ง, หยุดเมื่อเทสต์ผ่านทั้งหมดและ `/api/health` ตอบ 200
การ merge เข้า `main`, เปิดสู่อินเทอร์เน็ต และเก็บเงินจริง ต้องให้เจ้าของสั่งเท่านั้น
