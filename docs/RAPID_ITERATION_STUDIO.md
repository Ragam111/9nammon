# Token LCA — Rapid Iteration Studio

เอกสารนี้บันทึกว่าแต่ละไฟล์ทำหน้าที่อะไร และต่อระบบอะไรทำหน้าที่
ไม่ได้ใส่โค้ดใหม่ลงโปรเจกต์

ใช้ฟรี ข้อมูลส่วนตัวแยกตามบัญชี บันทึกส่วนตัวอยู่กับบัญชีที่ล็อกอิน
โทเคนบริษัทเป็นรหัสสิทธิ์ของสเปซ ไม่ใช่เหรียญ

## เจ็ดขั้นก่อนจะเปิดแอปได้

1. บริบท — `README.md`, `SKILL.md` บอกว่าใช้ฟรี แยกข้อมูลส่วนตัว และกติกาอ่าน → ตรวจ → เสนอ → รายงาน
2. โจทย์ — หนึ่งประโยคก่อนเป็นแอป เว็บ หรือตัวติดตั้ง
3. หน้าบ้าน — โครงแชทและช่องพิมพ์ ยังไม่เรียกโมเดล
4. หลังบ้าน — `server.py` ผูก `127.0.0.1`, สเปซแยกบันทึกส่วนตัวกับบริษัท, ล็อกอินแล้วคำถามต้องกรองด้วยผู้ใช้จากเซสชัน
5. อัดเซสชัน — `chat_history.json` และ `CHANGELOG_local.md` เป็นไฟล์ ไม่ใช่ความจำในแชท
6. คนกับเอเจนต์ — `app/agent` เสนอ, `local_coder.py` เขียนทับได้เฉพาะคนตอบ `y`
7. เปิดตัว — `install.ps1`, `LCA-Desktop.exe`, `start-lca.bat` ประกอบจากไฟล์ที่อัดไว้ในเซสชัน

## กฎที่ยังใช้อยู่

เอเจนต์อ่าน ตรวจผลกระทบ แล้วเสนอ diff คนเป็นคนอนุมัติก่อนเขียนทับ
ถ้าตอบ `n` ให้เก็บบันทึกไว้ในเซสชัน ไม่เขียนทับไฟล์
