# รัน LCA บน 2 เครื่อง (PC + โน้ตบุ๊ก) สลับเปิดปิดได้ ไม่เสียค่าเช่า

ทั้งสองเครื่องรันโค้ดชุดเดียวกัน (`server.py`) และ Ollama ของตัวเอง เครื่องไหนเปิดอยู่ก็ให้บริการได้

## 1. ติดตั้งครั้งแรก (ทำบนทั้งสองเครื่อง)
```powershell
git clone https://github.com/Ragam111/9nammon.git
cd 9nammon
python -m pip install -r requirements.txt
ollama pull qwen2.5-coder:0.5b
```

## 2. เปิดระบบ (ทำบนเครื่องที่เปิดอยู่)
1. เปิดแอป Ollama (ตั้งให้เริ่มเองตอน login จะไม่หยุดเองเหมือนเปิดจาก shell)
2. ตั้ง token ร่วม แล้วเปิดเซิร์ฟเวอร์ให้เครื่องอื่นใน LAN เข้าได้
```powershell
$env:LCA_TOKEN = "<token เดียวกันทั้งสองเครื่อง เก็บใน password manager>"
python server.py "$env:USERPROFILE" --host 0.0.0.0 --port 8420
```
3. ตรวจว่าพร้อม (ต้องได้ 200)
```powershell
curl.exe -s -o NUL -w "%{http_code}`n" http://127.0.0.1:8420/api/health
```

ถ้าพอร์ต 8420 ถูกใช้อยู่ เซิร์ฟเวอร์จะย้ายไปพอร์ตว่างเองและพิมพ์พอร์ตใหม่ออกมา (ไม่เปิดซ้อนแล้ว)

## 3. ให้สองเครื่องรู้จักกัน (cluster)
บนเครื่องที่เป็นหลัก หน้า `/dev` (สิทธิ์ ADMIN) มีปุ่มค้นหาเครื่องใน LAN หรือเรียก API:
```powershell
curl.exe -H "X-Auth-Token: $env:LCA_TOKEN" "http://127.0.0.1:8420/api/nodes/sync"
```
เครื่องหลักจะส่งงานแชตไปเครื่องที่ว่างและยังตอบ `/api/health` ได้ ถ้าเครื่องไหนปิด งานจะไม่ถูกส่งไปที่นั่น

## 4. ลูกค้าเข้าทางไหนเมื่อสลับเครื่อง
| ช่วง | วิธี | ค่าใช้จ่าย |
|---|---|---|
| ใน LAN (ตอนนี้) | ให้ลูกค้าเก็บ 2 ที่อยู่ไว้: PC `http://192.168.2.44:8420` และโน้ตบุ๊ก `http://<IP โน้ตบุ๊ก>:8420` เปิดตัวที่ใช้ได้ | ฟรี |
| ผ่านอินเทอร์เน็ต (ภายหลัง) | Cloudflare named Tunnel ตัวเดียว แต่รัน `cloudflared` บนทั้งสองเครื่อง (replica) Cloudflare ส่งคำขอไปเครื่องที่ออนไลน์ให้เอง | แผน Free + ค่าโดเมน |

ข้อสำคัญก่อนเปิดผ่านอินเทอร์เน็ต: ต้องทำงานกะ 2 ข้อ 1–3 ให้เสร็จก่อน (IP จริงหลัง tunnel, rate limit ต่อผู้ใช้, บัญชีใน SQLite, Google login) ดู `docs/SOFTWARE_ENGINEER_AGENT_MAP.md`

## 5. อัปเดตโค้ด (ทำทีละเครื่อง ลูกค้าใช้อีกเครื่องระหว่างนั้น)
```powershell
cd 9nammon
git pull --ff-only origin main
python -m pip install -r requirements.txt
```
แล้วปิดเซิร์ฟเวอร์เดิม (Ctrl+C ในหน้าต่างนั้น) และเปิดใหม่ตามข้อ 2
หรือดาวน์โหลด `lcalocalai.exe` ตัวล่าสุดจาก GitHub Actions/Releases แทนการใช้ git

## ข้อจำกัด
- RAM 8 GB รันโมเดลได้ทีละ 1 ตัวเป็นหลัก รับผู้ใช้แชตพร้อมกันได้ราว 9–13 คนต่อเครื่อง (ผลวัดกะ 0/1)
- ข้อมูลบัญชีและประวัติแชตเก็บแยกในแต่ละเครื่อง ยังไม่ซิงก์กัน ลูกค้าที่สลับเครื่องจะไม่เห็นประวัติเดิม (เป็นงานของกะ 2 ข้อ 2 เมื่อย้ายไป SQLite)
