# rapid-iteration-ecosystem

สกิลนี้เป็นลำดับทำงาน ไม่ใช่บทความ อ่านทีละขั้น แตะเฉพาะไฟล์ของขั้นนั้น
อย่ากระโดดไปแพ็ก .exe ก่อนมีแชท และอย่าเก็บข้อมูลส่วนตัวก่อนมีพื้นที่ที่ผูกเซสชัน

บริษัท **Token LCA** คือชื่อชุดติดตั้งของ Local Code Assistant
ต้นทางโค้ดอยู่ที่ https://github.com/Ragam111/9nammon
ใช้ฟรี รันในเครื่องเป็นค่าเริ่มต้น

## โทเคนห้ามปนคำ

- **context token** คือเพดานความจำของโมเดล `/reset` ล้างบทสนทนา ไม่ใช่การเติมเงิน
- **รหัสไททัน** คือสิทธิ์ผู้ดูแลระดับ CEO ไม่ใช่เหรียญที่โอนได้
- **มิเตอร์ usage** ใน `app/conn_usage.py` จดโหลดของการเชื่อม ไม่ใช่กระเป๋าเงิน
- **เครดิตสตูดิโอใน Forge** คือแต้มว่าเรียนขั้นไหนจบแล้ว คนละเรื่องกับสามข้อบน

ไม่มีขั้นตอนในสกิลนี้ที่ให้สร้างเหรียญซื้อขาย

## ลำดับสร้าง

01. **บริบท ก่อนมันจะเป็นแอป** — ล็อกโจทย์ให้นิ่ง แล้วทุกไฟล์ถัดไปมีที่อ้างอิง
02. **แชทพื้นฐาน** — ทำให้ถามแล้วได้คำตอบหนึ่งรอบ บนเครื่องตัวเอง
03. **ตอบทีละคำ** — เปิดท่อ SSE ให้คำเดินจากโมเดลมาถึงช่องแชท
04. **วัดก่อนเชื่อ** — เลือกโมเดลตามแรม และจำกัดงานพร้อมกัน
05. **ล็อกอิน แล้วแยกข้อมูล** — แยกผู้ใช้ สิทธิ์ และพื้นที่ ก่อนจะมีทีม
06. **เอเจนต์ คน และสกิล** — แยกแชทคน ออกจากงานที่เอเจนต์ทำซ้ำได้
07. **ชั้นโชว์แอป** — ทำให้ของที่สร้าง โชว์ได้ทีละชั้น
08. **โทเคนสามความหมาย** — ตั้งชื่อให้ถูก เพื่อไม่ให้คนเข้าใจว่ากำลังซื้อสินทรัพย์
09. **อัดเซสชัน เป็นไฟล์ติดตั้ง** — ปิดงานหนึ่งรอบให้เป็นไฟล์ที่คนต่อไปเปิดแล้วรู้ว่าต้องทำอะไร

ต้นฉบับเต็มอยู่ใน Forge ของแอป ไฟล์นี้คือแม่แบบสาธารณะไม่ใช่เหรียญ
