# รายงาน Agent 4 (ตรวจซ้ำแล้ว): รับบัตรเครดิต/เดบิต + PromptPay สำหรับ LCA (เปิดตัว 28 พ.ย. 2026)

รอบตรวจซ้ำนี้ค้นเว็บ 3 ครั้ง (Omise, Stripe TH, PayPal TH) เจ้าอื่นยังไม่ได้ตรวจซ้ำ ช่องไหนยังเขียน **[ยังไม่ยืนยัน]** ให้เช็คกับเว็บหรือฝ่ายขายของเจ้านั้นเอง

## 1) จ่ายเข้า PromptPay ด้วยบัตรเครดิตโดยตรงได้ไหม
**ไม่ได้ในรูปแบบปกติ** PromptPay ตัดเงินจากบัญชีธนาคารหรือ e-wallet ถ้าจะรับบัตรต้องใช้ gateway หรือ acquirer **[ยังไม่ยืนยันจากเอกสาร BOT/NITMX ข้อนี้อนุมานจากหลักการทำงานของ PromptPay]**

## 3) คำแนะนำ
**สัปดาห์เปิดตัว (เหลือ 2 วัน)**
- ใช้ PromptPay static + admin กดยืนยันเหมือนเดิม
- **แก้ไข:** Stripe TH เปิดบัญชีแบบ Individual ได้ จึงเป็นตัวเลือกที่ดีกว่า PayPal ถ้า KYC ผ่านทัน ได้ทั้งบัตรและ PromptPay ในเจ้าเดียว (ค่าธรรมเนียมยังไม่ยืนยัน)
- ทางสำรองคือ PayPal: 3.90% + 11 บาทต่อรายการ ค่าคงที่ 11 บาทกินสัดส่วนมากเมื่อยอดต่อรายการเล็ก
- ยังไม่ต้องทำตัดบัตรอัตโนมัติรายเดือน

**ช่วงถัดไป (1–2 เดือน)**
- จดทะเบียนพาณิชย์ จะสมัครธนาคารและ gateway ไทยได้อีกหลายเจ้า
- เทียบระหว่าง Omise (บัตร 3.65% และ PromptPay 1.65% บวก VAT) กับ Stripe TH
- ขอใบเสนอราคาจาก ChillPay, GB Prime Pay และ Ksher [ยังไม่ยืนยัน]
- ใช้ QR ร้านค้าของธนาคารคู่กับ gateway สำหรับบัตร

**สิ่งที่เจ้าของต้องทำเอง:** KYC, เซ็นสัญญา, ตั้งค่า payout, เก็บ live key ไว้ใน env หรือ secret ส่วนเกณฑ์จด VAT ที่รายได้เกิน 1.8 ล้านบาทต่อปีไม่ได้ตรวจซ้ำ ให้ปรึกษานักบัญชี

**สิ่งที่ต้องแก้ในโค้ด:** ใช้ข้อ 1–8 ตามรายงานเดิม (hosted checkout/SAQ-A, ตรวจลายเซ็น webhook ด้วย raw body, idempotency ผ่าน event_id ที่ unique, คิดราคาฝั่ง server, state machine ของ order, แยก env sandbox กับ live, async + retry, เก็บ static QR เป็น fallback) ข้อเหล่านี้เป็นแนวปฏิบัติทั่วไปที่ไม่ขึ้นกับค่าธรรมเนียมหรือคุณสมบัติผู้สมัคร จึงไม่ได้ตรวจกับเว็บในรอบนี้
