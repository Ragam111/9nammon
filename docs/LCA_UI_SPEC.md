# LCA UI spec (หน้าตาใหม่ ฐาน app/)

สรุปจาก Agent ออกแบบ 2026-11-26 (อ่านจากโค้ดจริง)

## กติกา
- ฟีเจอร์ทุกตัวที่มีตอนนี้ต้องอยู่ครบ เข้าถึงได้ภายใน 2 คลิก คีย์ลัดเดิมใช้ได้ทั้งหมด
- ใช้แบรนด์ LCA เอง (IBM Plex Sans Thai + สีใน app.css) ไม่ใช้โลโก้/ไอคอน/ชุดสีของ Claude หรือ OpenAI

## ฟีเจอร์ที่ห้ามหาย (ตามหน้า)
- /chat: แชตใหม่ (Ctrl+N), ค้นหา (Ctrl+K), โฟลเดอร์/โปรเจกต์, ปักหมุด, โหมดชั่วคราว, เลือกโมเดล + custom (Ctrl+Shift+M), เทียบหลายโมเดล, persona, export/import JSON, ป้ายออฟไลน์, คำถามตัวอย่าง, โหลดข้อความเก่า, ตอบใหม่, แตกสาขา, คัดลอก, เวอร์ชันข้อความ, ArrowUp แก้ข้อความล่าสุด, Esc หยุด stream, คัดลอกโค้ด, Enter/Shift+Enter, สถานะ Ollama
- /: แชต guest, เลือกโมเดล/ภาษา, Todo, เมนูมือถือ
- /login: user/pass หรือ API key/token, ออกจากระบบ
- /models: แนะนำ qwen, ติดตั้งพร้อม progress, รายการที่ติดตั้ง, ตัวอย่าง API
- /console: Overview 3 ขั้น, Connections/Skills/Bots, Playground, Usage
- /spaces, /support (admin เปลี่ยนสถานะได้), /dev (admin), /install

## โครงหน้า
- Desktop: grid `260px | 1fr | 320px`
  - ซ้าย: + แชตใหม่, ค้นหา, โฟลเดอร์, รายการบทสนทนา (ปักหมุดบนสุด), ลิงก์ Models / API keys / Spaces / Support / Settings, ชิปสถานะ Ollama + โควตาติดด้านล่าง
  - กลาง: หัวแชตมีแค่ชื่อแชต + เลือกโมเดล; เทียบ/persona/export/import/โหมดชั่วคราวอยู่ในเมนู "⋯"
  - ขวา (พับได้ จำค่า): การ์ดโมเดล, ไฟล์แนบ (`#attachments`), โควตาวันนี้, แผงเทียบโมเดล
- มือถือ (≤720px): แถบบน ☰ | ชื่อแชต | ⓘ, แถบซ้ายเป็น drawer (ปิดด้วย ✕/Esc/แตะพื้นหลัง), แผงขวาเป็น bottom sheet, ช่องพิมพ์ติดล่าง, ปุ่ม ≥44px

## ตัวชี้วัด "ใช้ง่ายกว่า"
1. เปิด /chat แล้วส่งข้อความแรกได้โดยไม่ต้องคลิก (โฟกัสช่องพิมพ์อัตโนมัติ)
2. สถานะ Ollama และโควตาเห็นทุกหน้า อัปเดตทุก 30 วินาที
3. ปุ่มหลักหนึ่งปุ่มต่อหน้า
4. หัวแชตไม่เกิน 3 ตัวควบคุม (ตอนนี้ 7)
5. ไปหน้าใดก็ได้ใน 1 คลิก (มือถือ 2 แตะ)

## งาน (ทำทีละชิ้น)
1. API โควตาแบบอ่านอย่างเดียว (`/api/me` หรือ `/api/me/quota`) ใน `server.py` + `app/org_store.py` — เทสต์: เรียกแล้วไม่หักโควตา, ไม่มี key = 401, guest ได้ guest quota
2. โครง 3 ส่วนบน desktop ใน `app/chat.html/css/js` (ไม่แตะ logic stream) — เทสต์: element id เดิมอยู่ครบ, แผงขวาพับได้และจำค่า
3. drawer + sheet บนมือถือ — เทสต์: 375x812 ไม่มี scroll แนวนอน, ปิดด้วย Esc/แตะพื้นหลัง, `aria-expanded` ถูกต้อง
4. แถบซ้ายและชิปสถานะร่วมกันทุกหน้า (`renderShell()` ใน `app/app.js`) — เทสต์: ทุกหน้าใน STATIC_ROUTES มีลิงก์ nav ครบ, primary button 1 ปุ่มต่อหน้า (ทำหลังงาน 1)
หมายเหตุ: งาน 2–4 ต้องเริ่มหลังสาขาไฮไลต์โค้ด/แนบไฟล์ merge แล้ว; งาน 1 เริ่มหลังสาขาแก้ช่องโหว่ merge แล้ว (แก้ server.py ส่วนโควตาเหมือนกัน)
