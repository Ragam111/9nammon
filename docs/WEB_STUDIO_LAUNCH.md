# Token LCA Studio — เทปเซสชันบนเว็บ

คู่กับ [`TOKEN_LCA_STUDIO.md`](TOKEN_LCA_STUDIO.md) และคอร์ส [`APP_WALKTHROUGH.md`](APP_WALKTHROUGH.md).
เอกสารนี้คือสัญญาของสตูดิโอเว็บที่เดินเรื่องเดียวกับรีโปนี้
ไม่ใช่ตัวติดตั้ง Windows และไม่แทน `server.py`.

อัปเดต: 2026-11-07 · สาขา `main`

## ใช้ฟรี กับของที่ต้องล็อกอิน

| บนหน้า | แขก | บัญชี |
| --- | --- | --- |
| สตูดิโอ | แปดขั้นทีละชั้น ว่าไฟล์ไหนรับอะไร ส่งต่ออะไรต่อ | ไม่บันทึก จนกดเก็บเข้าบัญชี |
| แชท | ส่งได้ทันที คำตอบอยู่แค่หน้า | ถังส่วนตัว / บริษัท แยกกัน หัก 1 โทเคนต่อคำตอบที่เก็บ |
| ไฟล์ | ดูเทปของบัญชี | TAPE.md และ TAPE.json |
| ติดตั้ง | ลำดับก่อนห่อเป็น .exe | ไม่มี |
| คอนโซล | โควตา สมอง สภา | มติสภาเขียนเทป ไม่ปนแชท |

แขกใช้สตูดิโอ แชท และสภาได้ทันที.
คำตอบของแขกอยู่แค่หน้า ไม่ถูกเขียนลงเซิร์ฟเวอร์ และไม่ถูกยกเข้าบัญชีที่หลัง.

## โทเคนบริษัท

ไม่ใช่เหรียญซื้อขาย และไม่ใช่รหัสผ่านร่วมทั้งบริษัท.

- เริ่ม 8,000 หน่วยต่อบัญชี
- หัก 1 เมื่อคำตอบแชทหรือมติสภาถูกบันทึก
- เทปสตูดิโอที่ผู้ใช้จดเองไม่หัก
- หมดแล้วปฏิเสธชัดเจน ไม่เรียกสมองต่อ ของเก่ายังอยู่ของบัญชีนั้น

ตัวนับบนเดส์ท็อปยังคือ `usage_store.py` กับ `conn_usage.py`.
บนเว็บสมองที่ตอบคือแผนที่ไฟล์ ไม่ใช่ Ollama.
ต่อสมองจริงที่ `console.html` ผ่าน `connections.py`.

## รูปไฟล์เทป

```json
{
  "title": "ชื่อเรื่อง",
  "source": "chat",
  "space": "private",
  "steps": [
    {
      "at": "2026-11-05T00:00:00.000Z",
      "layer": "backend",
      "file": "server.py",
      "action": "จัดเส้นทาง",
      "detail": "do_POST เข้าตัวจัดการแชท"
    }
  ]
}
```

- `source` คือ `chat` | `council` | `studio`
- `space` คือ `private` | `company` | `studio`
- `layer` คือ `frontend` | `backend` | `core`
- Markdown เป็นตาราง เวลา, ชั้น, ไฟล์, สิ่งที่เกิด

ชีพจรหนึ่งข้อความบนเว็บ แปดจังหวะจากคอร์สในรีโป:

1. `app/chat.js` ส่งข้อความ
2. `server.py` จัดเส้นทาง
3. `app/auth_backend.py` รู้ว่าใคร
4. `app/space_store.py` เลือกถัง
5. `app/admission.py` ยามเครื่อง
6. `app/context_manager.py` ตัดความจำ
7. `app/model_backend.py` สมอง
8. `app/history_store.py` บันทึกหรือไม่ คู่กับ `app/usage_store.py`

สภาไม่เขียนลงช่องนั้น. มติไปเทปของตัวเอง ผ่าน `app/agent/personas.py`, `harness.py`, `core.py`.

## สถานะสตูดิโอเว็บ — 2026-11-07

ห้าหน้าเว็บเดินสัญญาฉบับนี้ครบห้าหน้าแล้ว ก่อนห่อ `LCA-Desktop.exe`.

- แขกส่งแชทและเรียกสภาได้ คำตอบอยู่แค่หน้า ไม่ถูกเขียนลงเซิร์ฟเวอร์
- บัญชีแยกถัง `private` กับ `company` เทปแยกแหล่ง `chat` | `council` | `studio`
- โทเคนบริษัทเริ่ม 8,000 หักเมื่อเก็บบทแชทหรือมติ ไม่หักเทปสตูดิโอ
- สมองบนเว็บยังเป็นแผนที่ไฟล์ เลือกในเครื่องหรือ Token LCA Cloud ได้ที่คอนโซล คลาวด์จริงยังผ่าน `connections.py` บนเดส์ท็อป
- ดาวน์โหลด `TAPE.md` และ `TAPE.json` ตามรูปด้านบน พร้อมสกิล `rapid-iteration-ecosystem`

คนในทีมบนเว็บ: สถาปัตยกรรม, ช่างแชท, ผู้ดูแลข้อมูล, ช่างติดตั้ง.
ตัวติดตั้ง Windows ยังอยู่ที่รีโปนี้ ไม่ได้ย้ายไปอยู่ในสตูดิโอเว็บ.
